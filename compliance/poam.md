# Plan of Action & Milestones (POA&M)

A POA&M lists each requirement that isn't fully met, the risk, and the plan and date to fix it.
In CMMC Level 2, only some requirements may be on a POA&M at certification, and items must be closed
within a set time. Check current CMMC program rules before relying on specifics.
